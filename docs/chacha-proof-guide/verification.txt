Public Cha-Cha theorem
---------------------

File: ChaChaAll.lean (relative to the repository root)
Namespace: DynamicOptimality.ChaCha.All

For every finite key universe, every supplied initial BST, and every finite
request word X, a fixed deterministic mathematical online strategy has an
actual search-and-rotation execution. Its cost satisfies

  cost(initial, X) <= 3237120000456 * (OPT(X) + n) * iteratedLog 3 n.

Here n is the number of keys, OPT is the shared attained offline optimum,
and iteratedLog is the shared stabilized base-two iterated logarithm.
The public endpoint is

  third_log_competitive :
    DynamicOptimality.Competitive cost (Splay.Analysis.iteratedLog 3).

Each request costs its depth in the actual tree before the request, plus
one, plus the number of actual ordinary rotations. All other computation
is free. The transition depends only on the present state and request.
Classical choice is accepted for this abstract theorem; an executable
implementation or a bound on computation is not asserted.

The strategy, initial_tree, execution, online, cost_bound,
third_log_cost_bound, third_log_competitive, and competitor_bound results
record the strategy and its legality, exact initialization, prefix
consistency, cost bound, and comparison with every actual competitor.

The arbitrary-size extension uses a larger virtual universe only in the
internal state and projects its execution to the original keys. The
physical tree contains exactly those original keys, starts at the supplied
BST, and does not reinitialize between requests. Empty input costs zero.
